// before you install

Prerequisites

The app runs on your Mac. Install these once so image processing, video export, and optional AI logo placement work smoothly.

macOS

macOS 13 Ventura or newer. Apple Silicon (M-series) recommended; Intel Macs also work.

ffmpeg Required

Needed for video frames and video export. Install with Homebrew:

brew install ffmpeg

LLM (optional)

Logo placement can use a local or remote vision model. Configure in the app under LLM service — Ollama, PortKey / OpenAI-compatible proxy, or built-in placement with no AI service.

If using Ollama

Install and pull a vision-capable model, then point the app at it:

brew install ollama
brew services start ollama
ollama pull gemma4:31b

Image-only workflows work without an LLM. Video export requires ffmpeg on your PATH. First launch may take a few seconds while the local server starts.

// why local wins on cost

Same job as the SaaS tools — without the monthly bill.

Cloud editors and AI post generators meter usage and charge subscriptions. Content-sprout is free and open-source; optional AI can run on your machine via Ollama, so inference costs stay near zero after you download a model.

Content-sprout + local model

~$0/month

App is MIT-licensed. Core cropping, logos, layers, and export need no AI. Point logo placement (or assists) at Ollama — you pay in disk and RAM, not API tokens.

Typical cloud stack

$10–$50+/month

Canva, CapCut Pro, Predis.ai, and similar tools stack subscriptions, export limits, and per-generation credits — plus your photos leave your device.

Cloud LLM APIs alone

Per token

Vision models for layout or captions bill every request. A local vision model via Ollama avoids that meter entirely once the model is on disk.

// get started

Install and open

Download the macOS package, open the app, and the editor launches in your browser. Projects and assets stay on your machine.

  1. Install ffmpeg (and optionally Ollama or an LLM proxy).
  2. Download the macOS ZIP or DMG from GitHub Releases and move Content-sprout to Applications.
  3. Open the app (right-click → Open the first time if Gatekeeper prompts).
  4. Configure LLM service in the header if you want AI-assisted logo placement.
