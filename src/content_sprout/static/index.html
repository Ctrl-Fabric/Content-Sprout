                menu_book Content-sprout walkthrough

                A guided tour of how the app fits together — jump to the section for the screen you are on.

                1. Projects — pick or create a project from the header (shared by all tools).
                2. Assets & posts — upload photos/videos/audio, set project logos, then create image or video posts.
                3. Editor — place layers on the canvas, time them on the timeline (video), then export.

                Everything stays on this computer. Use Settings for LLM / ComfyUI options, and About for privacy and AI notes.

                Projects (header)

                1. Use the project control in the header to select or switch projects — it applies to every tool.
                2. Click New to create a project (brand, campaign, client).
                3. Click All (or the project name) to browse and open any project.
                4. Delete a project from the Posts & assets workspace only when you are sure — assets and posts inside it are removed from this machine.

                Assets

                1. Click Add assets to upload project-shared photos, videos, or audio (choose a group and logo option in the dialog).
                2. Optionally assign a group when uploading, and use Manage groups in Assets to create or delete groups (files are kept).
                3. Browse the library with Images / Videos / Audio / Logos tabs. Group filters narrow the list. Only project-shared assets appear here.
                4. Use Search free assets to search openly licensed stock and download into this project.
                5. Under Logos, set dark/light × short/full marks used when watermarking is on.

                Posts

                1. Click + New post and choose image or video.
                2. Open a post card to enter the editor. Breadcrumb: project → post.
                3. Post-private assets can be uploaded from inside the editor’s Post assets tab.

                Three columns

                1. Timeline (left): scenes and timed layers. Click a layer on the timeline or canvas to open properties here.
                2. Project assets / Post assets (middle): drag media onto the timeline (video) or canvas (image).
                3. Preview (right): the live stage. Drag to move layers; corner handles resize.

                Canvas & layers

                1. Use + Text / + Voice above the timeline, or drop media from the assets column.
                2. For image/video layers, use the texture control to add transparency masks (holes so layers below show through).
                3. Masks appear as amber sub-rows on the timeline and have their own timing and properties.

                Video timeline

                1. Scenes sit on the top track; layers (and masks) sit below across absolute time.
                2. Drag bars to move; use edge handles to trim duration. Playhead scrubbing updates the preview.
                3. Generate voice audio from a TTS layer, then export the reel (requires ffmpeg).

                Export

                1. Export image or Export video from the project chrome when a post is open.
                2. Use the breadcrumb project name to return to Assets & posts without leaving the project.

                About Content-sprout

                What it does, where your files live, and how AI is used.

                What this is

                Content-sprout helps you turn photos and videos into ready-to-share posts. Create projects for image or video posts, add assets, place text and image layers, build multi-scene reels, and export the result.

                Your files stay on this computer

                • Projects, uploads, processed images, and exports are stored locally — nothing is uploaded to a remote server.
                • Desktop app data lives under your user library folder; when you run from source, files stay in the project folders on disk.
                • Deleting a project or asset removes it from your machine. There is no cloud backup from this app.

                AI & logo placement

                • When logo placement is uncertain, the app can ask an AI vision model for help. You control this under Settings.
                • Built-in placement — works fully offline; no AI service is contacted.
                • Ollama — connect to models you host locally (for example Gemma) on this Mac or your network.
                • LLM proxy — route requests through services like PortKey or other OpenAI-compatible gateways. Your API key and traffic go only to that provider.
                • Text to voice — on video posts, voice layers use your Mac’s built-in speech (free, local) to create audio files that mix into the export.
                • Text to video — optional ComfyUI connection (e.g. Wan 2.1) generates clips on your machine; nothing leaves this computer.

                Things to know

                • Video export needs ffmpeg installed on this Mac (brew install ffmpeg).
                • The editor runs in your browser against a local server on this machine (typically 127.0.0.1). Keep this window open while you work.
                • Instagram publishing (if enabled) uses Meta’s APIs with credentials you configure; that is separate from local file storage.
                • This is a local-first creative tool — treat your machine as the source of truth for projects and media.
